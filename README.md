# Скоро втроём

Публичные учебные материалы для подготовки к родам и уходу за новорождённым в Израиле.

## Публикация в GitHub Pages

1. Создайте отдельный публичный репозиторий `skoro-vtroem` с README.
2. Загрузите содержимое этой папки в корень репозитория. `index.html` должен находиться в корне, а не во вложенной папке.
3. Откройте Settings → Pages → Build and deployment.
4. Выберите Deploy from a branch, ветку main, папку / (root), затем Save.
5. Дождитесь успешной публикации и откройте URL, показанный GitHub в разделе Pages.

Файл .nojekyll отключает обработку Jekyll. Сборка и зависимости не нужны.

## Данные посетителей

Сайт не содержит серверной базы данных. Отметки, вопросы и контакты сохраняются в localStorage текущего браузера, если браузер разрешает сохранение. Они не отправляются в GitHub и не синхронизируются автоматически. Раздел «Для двоих» позволяет скачать копию с прогрессом для ручной передачи партнёру.

Не загружайте в публичный репозиторий скачанные семейные копии, файлы прогресса и личные контакты. Ссылки на внешние материалы и шрифты обращаются к соответствующим внешним сайтам.

Информация предназначена для обучения. Индивидуальные рекомендации медицинской команды имеют приоритет.
